# Trip Timings Games · ألعاب تريب تايمنجز

منصة ألعاب HTML5 مجانية: لوبي + 5 ألعاب (الدومينو بأربعة أوضاع، CyberBreaker، فقاعات النيل، مستكشف مصر، عجلة الحظ اليومية) ومحفظة نقاط موحدة ونظام دعوة أصدقاء مع إعلانات تريب تايمنجز ومساحات جاهزة لـ Google AdSense أو أي شبكة إعلانات.

- **هيكل المشروع والإعلانات المتقاطعة:** [README-AR.md](README-AR.md)

- **نصوص Google Play (عربي/إنجليزي):** [store/](store/README.md)

Free browser games by Trip Timings with tourism cross-promotion and AdSense-ready ad slots. Static site: Nginx in Docker, or GitHub Pages.
