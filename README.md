# Trip Timings Games · ألعاب تريب تايمنجز

منصة ألعاب HTML5 مجانية: لوبي + 5 ألعاب (CyberBreaker، فقاعات النيل، مستكشف مصر، الثعبان النيون، عجلة الحظ اليومية) مع إعلانات تريب تايمنجز ومساحات جاهزة لـ Google AdSense أو أي شبكة إعلانات.

- **النشر المجاني بدون سيرفر (GitHub Pages)، والنشر على Coolify، وتشغيل AdSense:** [DEPLOY-AR.md](DEPLOY-AR.md)
- **هيكل المشروع والإعلانات المتقاطعة:** [README-AR.md](README-AR.md)
- **الملف الوحيد لإعدادات الإعلانات:** [`site/shared/ads-config.js`](site/shared/ads-config.js)

```bash
docker compose up -d --build   # http://localhost:8080
```

Free browser games by Trip Timings with tourism cross-promotion and AdSense-ready ad slots. Static site: Nginx in Docker, or GitHub Pages.
